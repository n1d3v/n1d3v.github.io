Welcome!

My Skills

I know a few languages, however I specialize in C# and Python mainly, but I have made C++ applications before. For the web, I use raw HTML and CSS with nearly no other frameworks involved. I'm also working on DirectUI documentation, you can find the source code for that here. I've also worked on a few Windhawk mods in the past, most notable being Classic Expand Buttons which adds the classic expand buttons from Windows 7.

My Projects

I'm working on a few projects at the moment, they are mainly to do with projects from around the 2010s era. One of my most popular projects at the moment is Classic 7, which is a Windows 10to7 mod that replicates Windows 7 nearly 1:1. Here's a list of the projects I am currently working on:

  • Skymu: A Skype-like instant messenger that supports many platforms, such as Discord and others.
  • CobaltSky: An easy-to-use and feature-complete Bluesky client for Windows Phone 8.1
  • DirectUI Documentation: A project that documents the undocumented markup language made by Microsoft.
  • GooBack: A fully custom frontend for Google that allows for the older designs to be used.
